# 016 — The board says a first name: a built-in name list, voiced once, fetched by id

- **Status:** Accepted, 2026-11-12 (the owner's decisions of that day: a built-in name list and no name from the database at any provider; where the name is said; the name-only clip, option A below). Decision 3 widened on 2026-11-13 at the owner's request: a name written with its surname or patronymic, either way round, is said by its first name («Nihat Əliyev», «Əliyev Nihat» → «Nihat»; `Language\Support\PersonName::firstName()`, the paste parser's surname rule, moved to `Language`), then also by the owner (same day) for a name of two words or more: the first word is the first name and whatever follows it is taken as the surname («Nicat mp», «Nicat M» without the dot, «Ayşən Nur» → «Nicat», «Ayşən»), unless the first word is the surname, written first as in a register («Əliyev Nihat» → «Nihat»), so a name made up on the board is said by its first name too, and so is a full name as ADR 018 stores it; a hyphenated first name («Ayşən-Nur») stays silent; and the display name rule now refuses a sure surname or a patronymic, as §7's minimum data always meant. The same day, also at the owner's request, «Never fuzzy» was narrowed: a name typed without the Azerbaijani letters («Lale», «Huseyn», «ILKIN»; `Az::plain()`) is said as the one listed name it can be, only the exact spelling when two listed names are typed the same; and the pages offer the list's spelling as a one-tap fix (`voice_spelling`). «Ali» is still not «Əli», nor «Nihad» «Nihat». Decision 4's order amended by the owner by ear (2026-11-12/13): the name before every phrase, and «Salam!» in the names' excited tone instead of `cheerfully`. Built the same day as the step called V2 here, after V1 of [015](015-voice.md) (architecture §3 "Voice"), and the clips made in the owner's paid month (d) on 2026-11-12/13: the 924 names of the first list and the three phrases; two changes to the outline below: the name clip is fetched by `nameClip()` in `http.ts`, a function beside `boardHttp()` rather than a member of it, since the board controller never fetches one; and the board's controller tells the scene of a turn and of the end through `BoardBridge.startTurn()` and `gameOver()`, so a change of student from the phone starts a turn too. Open for the owner before the paid month: the list itself, which the owner reviews (decision 1), and the name clips, which the owner hears one by one (decision 2).
- **Sections:** architecture.md §3 "Voice", §7, §8
- **Amends:** [015](015-voice.md) decision 6 ("No name is ever voiced"), its decision 11 (two switches become three) and its "(b) Names and teacher words" for names; 015 decision 7 (teacher words are not voiced) stands. architecture.md §0 (the owner decisions of 2026-11-11 and a line for 2026-11-12), D16, §3 "Where content lives" and "Voice", §7 ("Never on the wire or in logs", "Deletion", "Notice", "Parents and their children"), §8 "Voice", row 2 of "Open questions for the owner"; `CLAUDE.md`'s rule "Picture and number games". - **Why it is hard to reverse:** about two thousand clips of first names enter the repository under MIT, and every self-hosted copy carries them; they can be made only while the owner's account keeps the voice «Nigar – Ad Read» (about a year from 2026-11, ADR 015), so a name added after that cannot match the voice of the prompts; and once a board greets a child by name, families and classes expect it.

## Context

ADR 015 voiced every prompt and the praise, and decided that no name is ever voiced: a name is not known in advance, and voicing it on demand would send a child's name to a speech provider. Its "(b)" listed what a record that reopened names would have to settle: a provider that keeps no text, the privacy note and both agreements, a cache whose paths hold no name, deletion with the student or child, what a guest board's bearer may fetch, self-hosted instances without a key, and a call that cannot block a request while there is no queue.

The owner reopened it on 2026-11-12 and decided, not to be reopened here:

1. **A built-in name list.** Common Azerbaijani first names are voiced once, offline, in the voice and settings of `voice.json` (Nigar – Ad Read, `eleven_v4`), heard by the owner and committed as content. A student or child whose first name is on the list is voiced; any other name stays silent, and its text still shows. No name from the database ever reaches a speech provider: `content:voice` keeps reading no row, and an instance needs no key.
2. **Where the name is said:** with the praise after a solved round, only when the player is a chosen student or the home child; in a greeting at the start of a home game («Salam, Nihat!»); at the end of a game («Əla oynadın, Nihat!»). Not when «Kim oynayır?» picks a student, and never in rankings, on the podium or on the share card.

The list answers every point of 015's "(b)" at once: no provider is called at play or when a child is added, so nothing about a child is sent, retained or trained on; nothing new is stored, so the agreements do not change; a clip is list content, so nothing has to be deleted with a child; and a self-hosted instance plays the same files without a key. What is left is how a board gets a name's clip, and that is a trap.

**The URL trap.** Every clip of 015 is a public file at `/content/voice/{hash}.mp3`, and `content/voice-clips.json`, public in the repository, maps every hash to the text it was made from. Even without that file the hash can be computed by anyone: it is a SHA-256 of the settings in the public `voice.json` and the text. A board that loaded «Nihat!» from `/content/voice/{hash}.mp3` would therefore write the child's first name into a URL — into the access logs of the web server and the proxy, the browser's history and cache, and the `Referer` of anything that page loads — which §7 forbids for every name ("never a name in a URL"). The name clips need a way to the board that carries ids only.

**The list's source.** Checked on 2026-11-12:

- No official list with stated terms of reuse was found. The Ministry of Justice offers the e-service «Azərbaycan adları barədə məlumat» on `exidmet.justice.gov.az`, which looks up one name at a time (with its meaning and yearly statistics, by its regulation's description); it offers no list to download and states no terms, and its regulation's PDF answered 404 that day. It is not a source here.
- **Wikidata**, whose structured data is CC0 ([licensing](https://www.wikidata.org/wiki/Wikidata:Licensing)), has the given names of people with the citizenship of Azerbaijan. The query below, run at [query.wikidata.org](https://query.wikidata.org/) on 2026-11-12, returned 864 names; 588 of them have an Azerbaijani label that is one word of the 32 letters, 346 boys' names, 169 girls', the rest unisex or unmarked. It leans to notable adults (Əli 38 people, Nazim 28, Samir 26, Elçin 25, Vüqar 24): a seed, not a list of what children are called today.

- Wiktionary's "Azerbaijani given names" (297 pages) and az.wikipedia's categories «Kişi adları» (659 pages) and «Qadın adları» (274) are CC BY-SA 4.0 and smaller than the seed. `philipperemy/name-dataset` (Apache-2.0) is built from a leaked dump of a social network, which a children's app does not use whatever its license says. `sigpwned/popular-names-by-country-dataset` (CC0) has about twenty names a country.

**Cost.** Checked on 2026-11-12 ([API pricing](https://elevenlabs.io/pricing/api)): Eleven v4 costs $0.08 per 1,000 characters on every plan; Starter is $6 a month ($1 the first month) with 75,000 characters, Creator $22 ($11 the first month) with 275,000. The seed's names have 5.5 letters on average.

## Decision

1. **A built-in name list, `content/names.json`.** About 2,000 first names, roughly 1,000 girls' and 1,000 boys' (a name given to both is listed once): the names Azerbaijani children born from about 2015 are given, since a student is 6–10 years old and a parent's child 3–10. It is our own selection under MIT like the rest of `content/`: seeded from the Wikidata query above (CC0; the query and the date stand in this record and in the file's `sources`), completed by Elifba's contributors from the names in use, and reviewed by the owner before its clips are made; a name is a fact, and the selection is ours. Anyone may propose a name by a pull request; it is voiced in the next paid month while the voice lasts. **Spelling:** the modern Latin spelling of the 32 letters as families write it today, without the apostrophe of the old spelling («Məsumə», never «Mə'sumə»; the paste parser drops it too, §7); one word, no hyphen or space; a capital first letter and the rest lowercase. Two spellings in real use are two entries («Hüseyn», «Hüseyin»), each with its own clip; a misspelling is never listed. Foreign names are listed in Azerbaijani spelling, as a display name must be («Aleksandr», «Vilyam»). **Validator:** `sources` a non-empty list of https URLs; `names` non-empty, every name of 2–24 letters of the alphabet only, equal to `Az::title()` of itself, unique by `Az::lower()`, and the list in Azerbaijani order (`AzCollator`), so a duplicate sits next to its twin in a diff.
2. **Voiced once, offline, like every clip.** `php artisan content:voice` makes one clip per list name in the voice, model, settings and context of `voice.json`, with the tag of `voice.json`'s `names.style` (`excited`): the text sent is `[excited] Nihat!`. The hash is `VoiceClips::hash()` as for every clip, so nothing is paid for twice. The command reads `names.json`, never a row: no student's or child's name, and no teacher word, can reach the provider. The owner hears every name clip on the review page (015's) before the commit; a bad one is deleted and made again, or given a respelling in `spoken.respell`.
3. **The match is exact.** A display name is voiced when, after `Az::normalize()` (applied when it was saved) and without a trailing surname initial, it is one word on the list, compared with `Az::lower()` (so İ/i and I/ı follow Azerbaijani casing). «Əli M.» is said «Əli»; two students «Əli M.» and «Əli H.» are both said «Əli», as a teacher calls them; the board still shows the initial. A hyphenated first name («Ayşən-Nur») is silent. (Amended 2026-11-13, above: of two words or more the first is the first name and the rest is taken as the surname, «Ayşən Nur» → «Ayşən», «Nicat mp» → «Nicat», unless the first word is the surname.) Never fuzzy: «Huseyn» is not «Hüseyn» and stays silent until the teacher corrects the spelling. A name not on the list is silent; the board shows it as before, and the phrase is said without it.
4. **The name alone, before the phrase** (the owner's choice, form A). A name clip is the name only, «Nihat!». The board says the name, then the phrase, with a pause between them (`NAME_GAP_MS`, 150 ms, which the owner kept by ear): «Nihat!» … «Afərin!», «Nihat!» … «Salam!», «Nihat!» … «Əla oynadın!». The greeting is said in the names' tone, `[excited] Salam!`. (First written as the phrase, then the name; the owner chose this order and that tone by ear on 2026-11-12/13, after hearing the name clips both ways and «Salam!» in both tones beside them.) Never a name stitched inside a phrase, and never a name without its phrase.
5. **Where it is said.** With the praise after a solved round, when the player is a student chosen in a class game or the child of a home game; in the greeting of a home game; at the end of a game (decision 7). Not when «Kim oynayır?» or the phone picks a student, not for the whole class, not on a wrong tap (the retry phrase stays nameless), and never in rankings, on the podium, on the share card, on the phone or on the welcome page. The remote plays no sound, as before.
6. **How often the praise carries it.** A **turn** is the time one player is at the board: it starts when the board starts the game or opens it again (a reload; a pause does not end a turn), and whenever the student at the board changes (the board's students, «Növbəti», the phone, «Kim oynayır?»). The praise of the first solved round of a turn carries the name, and then every third: the 1st, 4th, 7th … solved round of the turn. A class whose teacher sends a new child to the wall every round hears every child's name at their round; a child playing ten rounds at home hears it four times. The whole class (no student chosen) never hears a name.
7. **The greeting and the end.** A home game's greeting is «Salam!» and the child's name, said when «Başla» starts a game with no answered round, before the first prompt (which waits for it); not on «Davam et» after a reload, and a class game has none. At the end of a game with at least one solved round the board says «Əla oynadın!» and the name of a home game's child, or of a class game's student when every round this board saw solved was solved by that student; when the whole class or more than one student played, «Əla oynadınız!», with no name; after no solved round, nothing. Where there is no name to say (not on the list, or names off), the phrase is said alone. The three phrases are content: `voice.json`'s `greeting`, `finish` and `finish_class`, built-in clips under `content/assets/voice/` like the praise.
8. **No name in a URL: a board gets a name clip through its game, by ids.** Name clips live in `content/voice-names/{hash}.mp3`, outside `content/assets`, so `storage:link` serves none of them and no public URL exists for one. A board gets a clip only from **`GET /games/{game}/players/{player}/voice`**: two ULIDs, never a name or a hash. The route sits with the board's routes (`auth:board,web`, `->can('play', 'game')`): a teacher's session reaches its own class games, a parent's its own home games, a guest board's bearer only the game its board shows. `{player}` must be one of that game's players, read through `GamePlayers`: an active student of the game's class, or the game's child; anything else is a 404 before a file is touched, and so is a player whose name has no clip, or a game whose owner turned names off. The answer is the MP3 with `Content-Type: audio/mpeg`, `Cache-Control: no-store, private` (no shared cache keeps it, and a shared school computer keeps no copy on disk), `X-Content-Type-Options: nosniff`, and no header naming the file. The board fetches it with its own HTTP client (`resources/js/game/http.ts`, a guest board's bearer in the `Authorization` header as for every board request) and keeps it only decoded in memory, never in `localStorage`. The board props carry, per player, that route's URL or null — ids only. The access log reads `/games/01J…/players/01J…/voice`, as it reads `/games/01J…/state`. `voice-clips.json` lists the name clips under its own key `names` (hash → text): that is the list, public anyway, and says nothing about who bears a name.
9. **A third switch.** Settings → Oyun gets «Adı səslə de» / "Say the name aloud" below «Tərif səsi», with the hint «Şagirdin və ya uşağın adı Elifba-nın ad lüğətindədirsə, lövhə onu tərifdə, evdə salamda və oyunun sonunda deyir.» / "When a student's or child's first name is in Elifba's name list, the board says it with the praise, in the greeting at home and at the end of a game." It is on for every account, a new one and one made before V2 (`users.board_voice` null or without `names` reads as on). «Tərif səsi» governs everything the board says besides the prompt — praise, retry, the greeting and the end — so with it off nothing is said and the name switch is shown disabled. A device's «Səssiz» silences names with everything else.
10. **The pages say which names the board can say.** On the class page's student list and on a child's card and page, a name the board can say carries a small speaker icon (`Volume2`, labelled «Lövhə bu adı səslə deyir» / "The board says this name aloud"), only while the account's names and praise are on. A name without a clip gets no mark of its own; instead the student list has one line under it when an active student's name has no clip: «Lövhə Elifba-nın ad lüğətindəki adları səslə deyir; başqa adları yalnız yazır.» / "The board says the names in Elifba's name list aloud and only shows the others."; a child's page says under the name: «Bu ad Elifba-nın ad lüğətində yoxdur: lövhə onu səslə demir, yalnız yazır.» / "This name is not in Elifba's name list: the board shows it but does not say it." Whether a name has a clip is derived on every request from the name and the list (`has_voice`), never stored.
11. **Deletion: a name clip is list content, not a child's data.** One clip serves every student and child of that first name on every instance. Deleting a student, a child, a class or an account deletes no clip and needs to delete none: nothing about any student or child is stored for the voice — no row, no column, no file. A clip leaves the repository only when its name leaves the list (`content:voice --prune`).
12. **Privacy.** Nothing new is stored, and nothing about a child is sent anywhere: the agreements of §7 do not change. A name is now said aloud in the room, where it was already written on the board; `/privacy` says so in a section of its own, «Lövhənin səsi» / "The board's voice": «Lövhə tapşırığı və tərifi əvvəlcədən yazılmış səslə deyir. Şagirdin və ya uşağın adı Elifba-nın hazır ad lüğətindədirsə, lövhə onu tərifdə, evdə oyunun əvvəlində və oyunun sonunda bu səslə deyə bilər. Ad heç bir xidmətə göndərilmir və bunun üçün heç nə saxlanılmır; lüğətdə olmayan ad yalnız yazı ilə görünür. «Ayarlar → Oyun» bölməsində söndürmək olar.», with the same in English. The note a teacher copies for a class's parents gains one sentence: «Lövhə uşağın adını, ad Elifba-nın ad lüğətindədirsə, tərifdə əvvəlcədən yazılmış səslə deyə bilər; ad heç yerə göndərilmir.»
13. **Cost and deadline.** One more Starter month ($6): the names take about 33,000 of its 75,000 characters, which leaves room for a second take of every name, for the three phrases and for prompts added since V1, so the run can share a month with other new content. It must happen while the voice lasts: in the next paid month, and by 2027-08 at the latest to keep a margin before the notice period ends. After the voice is gone a name added to the list stays silent, unless every clip — prompts and names, about 2,900, about 60,000 characters, one Starter month — is made again in another voice (015 decision 8: the voice is part of every hash).

## Implementation outline

Nothing below exists yet; the names are the plan. V2 updates the contract's text it builds (architecture §3 "Voice", §7, §8, `docs/frontend.md`, `CREDITS.md`) in the same change.

## Consequences

- A child whose first name is on the list hears it at the wall or at home; a child whose name is not hears the same praise without it. The list cannot hold every name, so the pages say which names the board can say, and a missing name can be added to the list while the voice lasts.
- The repository grows by about 15 MB of name clips (about 25 MB of voice in all), and the list is a file contributors maintain, reviewed like a pack.
- The name clips are the one content file a board cannot load from `/content/…`: one route, one controller and a `fetch` path in the board exist for them alone, and every test that enumerates routes lists it.
- A name is said aloud in the room. It was already written on the wall and on a home screen; a teacher or parent who does not want it turns one switch off.
- Two students with the same first name are said the same; the board shows their initials.
- After the voice's notice period a name added to the list stays silent until every clip is made again in another voice.
- Since a name's hash can be computed from the public list and settings, the rule that no URL carries one is what keeps names out of logs; the tests pin it.
- One more paid month, which can be shared with other new content.

## Alternatives rejected

- **Generating a name with ElevenLabs on demand** (when a student or child is added, or at play): the owner's decision 1 rules it out, and for the reasons of 015's Context — the name of a child goes to a provider in the United States that may train on inputs and offers zero retention only to enterprise customers; every instance needs a key; a call without a queue blocks a request; and the clip would have to be deleted with the child.
- **Azure AI Speech per name** (it keeps no text of real-time synthesis): still a third party for a child's name, a key on every instance, and a different voice from the prompts' (Banu or Babək, not Nigar).
- **Names recorded by the parent or the teacher:** a recording of an adult's voice and of the child's name is a new field about a child (013 decision 3), with a microphone flow, storage, deletion and moderation to build; and the clip would not match the board's voice.
- **Whole phrases per name (form B):** four times the clips, about 90 MB, a Creator month or three Starter months; the owner chose the name alone.
- **A public URL by hash** (`/content/voice/{hash}.mp3`, as for the prompts): the URL trap.
- **A URL keyed by an HMAC of the name with the app key:** the operator can still recover any name from the public list; the same name has the same URL across classes and instances' logs can be joined; and the file must still be served by PHP, so it gains nothing over ids.
- **The clip inline in the board props** (base64): the guest board polls its props every two seconds, and a class of thirty would add some 400 KB to every poll.
- **Sending the list to the browser and matching there:** the browser would then load the clip by its hash, the trap again.
- **Fuzzy matching** («Huseyn» → «Hüseyn»), or saying the first part of a hyphenated name: the board would say a name other than the one written. (A name of two words was in this list until 2026-11-13; the owner chose its first word, since a teacher writes the first name first and anything after it to tell two students apart.)
- **The praise's switch alone:** a teacher who wants praise but not names, or the reverse for a shy child at home, would have no choice.
- **A list of 10,000 names or more:** within one Creator month, but the long tail is rarely borne and hard to review by ear; the list can grow in any later paid month while the voice lasts.

## What would make us revisit

The voice becoming unavailable before the name clips are made; many children's names missing from the list (then the list grows, while the voice lasts); a school or parent objecting to a name said aloud; a self-hostable Azerbaijani speech model with a clear license and a named, consenting voice that could run on the instance, with no third party, and say any name; or a native speaker willing to record the names.
